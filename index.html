Features

Everything you need,
nothing you don't.

Built for developers who want a fast, private API client that stays out of the way.

Git Sync

Push and pull collections to any Git remote. Your team shares API definitions through version control — not a proprietary cloud.

HashiCorp Vault

Native Vault integration out of the box. Set a token and namespace, then sync your secrets — just like collections sync with Git.

Smart Environments

Define variables per collection or folder — they auto-switch as you navigate between requests. Use {{base_url}} and never touch a URL again.

Request Builder

Method, headers, query params, body, auth — with a syntax-highlighted editor and full import/export.

Collections

Organize requests into nested folders. Each collection gets its own environments, variables, and Git repository.

Local First

Runs on your machine as a native desktop app. Your data stays local — nothing is sent anywhere unless you choose to sync.

Install with Scoop (recommended)

Vaxtly isn't code-signed yet, so Windows SmartScreen will block the installer if you download it directly. Installing via Scoop bypasses this automatically. 

scoop bucket add vaxtly https://github.com/vaxtly/scoop-bucket
scoop install vaxtly

Don't have Scoop? Install it first.

Or download the installer directly (may trigger SmartScreen):

Download .exe from GitHub Releases →
Windows may show a SmartScreen warning — this is normal
  1. SmartScreen will show a "Windows protected your PC" dialog — click "More info".
  2. Then click "Run anyway" to proceed with the installation.

Why is the app unsigned? Code signing certificates require identity verification programs that aren't available in all countries, and third-party alternatives cost ~$500/year — prohibitive for an independent open-source project. The app is fully open source — you can audit the code and build it yourself.

Install with Homebrew (recommended)

Vaxtly isn't signed with an Apple Developer certificate yet, so macOS Gatekeeper will block the app if you download the DMG directly. Installing via Homebrew bypasses this automatically. 

brew install vaxtly/tap/vaxtly

Don't have Homebrew? Install it first: 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
